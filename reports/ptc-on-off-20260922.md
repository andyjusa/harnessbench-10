# PTC ON/OFF — HarnessBench-10

## Verdict

Do not enable PTC by default based on this run. PTC OFF passed all 10 tasks; PTC ON passed 9. PTC ON also used more model calls, tokens, time, and reported cost. This is a one-repetition descriptive result, not a significance claim.

## Fixed conditions

- Benchmark revision: `e7a48d2b3e81d4e97a1924e4b9a7c1ba698c87c4`
- Harness source HEAD: `bed5d9d5740e4c70aaecf084c58db572cd1f5a1f` (working tree contained the tested PTC toggle)
- `integration.mjs` SHA-256: `ec76d8b301b24ba4af0ee98525d78832c0775b65bbc98239447525e20377cb2f`
- `code-tool.mjs` SHA-256: `6afc46d0cb6ebba13a5c9285373d7ed50c3cefaeeb39d98b99ca35d95f1f6298`
- Pi 0.85.1; `openai-codex/gpt-5.6-sol`; thinking `low`
- One run per case and condition; fixed order OFF then ON
- Local temporary workspaces; identical fixtures, instructions, and verifiers
- Only `PI_PTC` changed between paired arms

## Aggregate results

| Metric | PTC OFF | PTC ON | ON vs OFF |
|---|---:|---:|---:|
| Correct | **10/10** | 9/10 | -1 task |
| Reported cost | **$0.5092** | $0.5977 | +17.4% |
| Wall time | **404.6 s** | 415.0 s | +2.6% |
| Model/backend calls | **52** | 62 | +19.2% |
| Tool calls | 53 | **52** | -1.9% |
| Input tokens | **49,578** | 59,748 | +20.5% |
| Output tokens | **7,732** | 8,542 | +10.5% |
| Cache-read tokens | **58,624** | 85,376 | +45.6% |
| Timeouts | 0 | 0 | — |

For lower-is-better paired metrics, PTC ON lost 7/10 cases on cost, 7/10 on latency, 7/10 on model calls, and 8/10 on output tokens. Tool calls were effectively tied (median paired delta 0).

## Accuracy failure

PTC ON failed `01-config-discovery`. It changed the script to search ancestors of the process working directory, then tested only from `project/tools`. The verifier executed from the workspace root; the required nearest configuration was a descendant there, so the script failed. PTC OFF passed the same fixture and verifier.

## Interpretation

The current PTC policy did not produce the intended batching benefit. It wrapped native operations in `execute_code` but made essentially the same number of underlying tool calls, while adding discovery/wrapper turns and context. The result supports changing PTC guidance or implementation before considering default enablement.

## Limitations

- One repetition; stochastic model variance is not estimated.
- Fixed OFF→ON order may introduce order/time effects.
- Local runner, not Harbor container execution.
- Backend calls are counted from assistant message completions; provider-internal requests are not independently observed.
- Reported costs are Pi usage metadata, not an external billing reconciliation.

## Pilot excluded

An earlier pilot used three underspecified prompts whose hidden verifier requirements were not stated. Those results were excluded. The prompts were corrected in benchmark revision `e7a48d2` and the complete 20-run campaign was rerun.
